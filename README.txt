CHM Preview + RuleDesk V1.3.6 — Cloudflare Pages 纯静态版
========================================================

部署
----
这是已经整理好的静态目录。Cloudflare Pages 使用 Direct Upload 时，直接上传本 ZIP 即可；
不需要 npm、不需要 Pages Functions，也不需要 Cloudflare Worker。

入口
----
/              通用 CHM 阅读器
/ruledesk/     RuleDesk 跑团规则书模式

首次从主页进入会询问默认模式，并将选择保存在浏览器 localStorage。
普通页顶部可进入 RuleDesk；RuleDesk 顶部也可返回普通阅读器并重新设置默认。

隐私与解析架构
--------------
CHM 文件不会上传服务器。阅读时由浏览器 Web Worker 按需读取 File.slice()，在本地完成
ITSF/ITSP、LZX、目录、索引、正文与资源解析。chm-worker.js 是浏览器 Web Worker，
与 Cloudflare Worker 无关。

RuleDesk V1.3：本地规则书架
---------------------------
1. 桌面文件句柄模式
   在支持 File System Access API 的桌面环境中，从“打开规则书 CHM”按钮选择文件时，
   RuleDesk 会把 FileSystemFileHandle 保存到 IndexedDB。CHM 本体仍留在原位置，
   不创建额外副本。下次从书架打开时直接读取原文件；如果浏览器未保留读取权限，
   会在用户点击该书时重新请求授权。

2. 手机 / 平板离线书架
   拿不到 FileSystemFileHandle 的场景会提示“保存到离线书架”。确认后，CHM 会复制到
   Origin Private File System (OPFS) 中，并在 IndexedDB 保存书籍信息。删除书架条目时，
   OPFS 副本与该书的搜索索引会一起删除。

3. 存储策略
   浏览器站点存储可能处于 best-effort 模式。保存 OPFS 副本时 RuleDesk 会调用
   navigator.storage.persist() 尝试申请持久化，但最终结果由浏览器决定。书架首页会显示
   “持久化 / best-effort”和当前站点存储用量；用户始终可以手动删除规则书。

4. 分级搜索索引
   加入书架后，.hhc/.hhk 的目录和关键词先写入轻量索引，可立即使用；随后独立
   index-worker.js 在后台逐页构建正文索引。阅读、翻页和当前书搜索仍由另一个 Worker
   负责。书架卡片及当前书标题旁会显示“正在构建索引 XX%”。

5. 拼音首字母与英文原词
   持久化术语索引会自动生成中文拼音首字母，并从正文短标题中提取英文原词。
   例如 jjgj 可匹配“借机攻击”；prone 可匹配“倒地 Prone”；grappled 可匹配
   “受擒 Grappled / 擒抱”。这些快速术语匹配不需要重新解压整本 CHM。

6. 跨书搜索
   当本地书架中保存多本规则书时，搜索范围菜单会在“搜索整本规则书”下面增加
   “搜索本地规则库”。结果按规则书分组；目录/术语结果先显示，已构建的正文索引随后
   返回正文命中。点击其他规则书的结果会先打开对应本地书，再跳到命中位置。

7. PWA / 离线外壳
   RuleDesk 带 manifest.webmanifest 与浏览器 Service Worker。安装后的网页外壳、解析器、
   RuleDesk 代码和图标可从缓存启动；保存到 OPFS 的规则书可在离线时读取。

兼容性
------
- 普通 CHM 阅读与 RuleDesk 不依赖服务器端解析。
- 桌面“0 副本书架”只在提供 showOpenFilePicker / FileSystemFileHandle 的浏览器中启用；
  其他浏览器仍可正常选文件，并在支持 OPFS 时使用离线副本模式。
- 超大 CHM 虽采用切片读取，但最终稳定性仍受设备内存、单个内部资源大小和 CHM 结构影响。

安全
----
规则页脚本、iframe、object、embed、form 等主动内容默认删除；外部链接默认禁用；内部资源
重写为本地 Blob URL，并在 sandbox iframe 中呈现。书架和索引均保存在当前浏览器站点空间。

许可证
------
CHM/LZX 解析实现包含 LGPL 来源的衍生实现，许可证见 LICENSES/LGPL-2.1.txt 和 NOTICE.txt。


V1.3.6：平板紧凑模式与 OPFS 兼容降级
------------------------------------------
- 手机与触控平板使用可收起侧栏和可收起顶部工具栏；检测基于输入能力而不只按分辨率，普通电脑保持桌面布局。
- 触控平板横屏（最高约 1400 CSS px）也会进入紧凑阅读模式，目录以覆盖层方式呼出，••• 展开更多工具。
- 离线书架不再强依赖 OPFS：优先 OPFS，若 navigator.storage.getDirectory 不存在或实际调用失败，自动回退到 IndexedDB Blob 存储。
- IndexedDB 离线副本同样可从书架直接打开、构建持久化索引，并可随书架条目一起删除。
- 如果 OPFS 与 IndexedDB 都不可用、被禁用或配额不足，RuleDesk 会保留“仅本次阅读”，不会阻止 CHM 正常打开。

- 手机与触控平板的搜索按钮改为开/关切换，并在搜索框右侧加入明确的“×”收起按钮。
- 点击搜索区域外或按 Esc 会收起搜索；执行 Enter 全文搜索后也会自动收起浮动搜索框，把空间还给结果与正文。

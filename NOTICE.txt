CHM Preview — static browser reader

This package is designed for static hosting (including Cloudflare Pages).
It does NOT require Cloudflare Workers or Pages Functions.

The file engine runs locally in the browser. The selected CHM is passed as a
File object to a browser Web Worker. The archive is read with File.slice()
and FileReaderSync as ranges are needed; the CHM file is not uploaded by this
application.

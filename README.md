# ChmReader / RuleDesk

纯浏览器、本地优先的 CHM 阅读器。项目包含两个入口：

- **CHM 阅读器**：面向帮助文档和技术手册的通用阅读模式。
- **RuleDesk**：面向 D&D 5E / 5R、COC 等跑团规则书的优化工作台，支持目录检索、多标签、双栏、链接预览、规则卡复制、本地书架和持久化索引。

## 当前版本

V1.3.6。手机/平板采用可收起目录与工具栏；移动端离线书架支持 OPFS，并在不支持时自动回退到 IndexedDB。宽表仍只在表格区域横向滚动。

## 部署

项目为纯静态网页，可直接部署到 Cloudflare Pages 等静态托管服务，无需服务端 CHM 解析。CHM 文件在浏览器本地由 Web Worker 按需读取。

## 本地存储

桌面端支持 File System Access API 记住原文件句柄；移动端可将规则书保存到 OPFS 离线书架。索引和阅读状态保存在浏览器本地。
